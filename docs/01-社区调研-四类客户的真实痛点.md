# 01 · 社区调研：四类客户的真实痛点

> 调研时间：2026-11-10  
> 渠道：知乎、小红书、微信公众号、今日头条、网易、行业媒体  
> 方法：搜索店主自述、经营复盘、行业分析，归纳高频痛点  
> 偏差提醒：社区内容天然偏“吐槽者”和“焦虑内容”，成功者不爱发言；个别行业数据来自自媒体，未核实，只能当情绪参考。

---

## 一、开商店的（便利店 / 小超市）

### 社区原话

- “货架越来越满，生意反而更难做。”——不是缺货，是顾客**没有购买理由**。
- “从烟柜到冰柜，库存正压垮个体老板。”
- “一天营业额破不了一千是常事。”
- 守店 12–17 小时，全年无休，不敢生病。

### 四层痛点

| 层面 | 具体痛点 |
|---|---|
| 收入 | 客流被零食折扣店、连锁便利店、即时零售、社区团购分流；进店只买烟水，客单价掉 |
| 现金 | 库存压资金、临期损耗、回本周期长；烟要按档位硬性打款，冷门烟积压亏本清 |
| 时间 | 人被店拴死，没时间做外卖、私域、学习 |
| 能力 | 不会选品、不会做社群、不会拍内容；知道要做线上，但不知道从哪下手 |

### 他们已经在用豆包做什么

- 查商品价格、库存：把进销存表格导入豆包，店员报货号就能报批发价和库存颜色、尺码。
- 写朋友圈推广文案、商品介绍、到店提示。
- 生海报、剪简单视频（豆包 + 剪映）。
- 看经营数据：部分平台（如抖音生活服务）已有“豆包工作”插件，可自然语言查交易 / 流量数据、生成经营报告。

### 已有付费替代

- 进销存 / 收银软件（秦丝等）。
- 外卖平台、社区团购平台。
- 本地短视频代运营 / 同城推广。

### 机会判断

- **最痛**：库存压钱 + 客流下滑。
- **最容易演示**：拍一张货架 / 冰柜照片 → 临期清单 + 本周补货建议 + 3 条朋友圈。
- **最难**：让老板持续录入数据；不要做又一个 dashboard。

## 二、卖茶叶的

### 核心矛盾

店变成了“仓库 + 会客室”，线下自然客流几乎消失。

### 痛点

- **获客**：靠熟客复购、节日礼品、单位采购撑着；散客积累极慢，3 公里生意受限。
- **内容**：老板拍茶室风景、泡茶日常，“自赏式内容”引来泛流量但不进店。有案例：广州茶城老板做两年抖音、发百余条、粉丝 2000 多，被隔壁刚做三个月的 90 后反超——后者拍“买普洱三个坑”“百元与千元普洱差别”。
- **库存**：春茶一批几万；绿茶 90 天、普洱 360 天周转警戒线；卖不出去就是“烂叶子”。
- **客户资产**：老客的喝茶偏好、价位、送礼节点全在老板脑子里或微信聊天记录里，换人接待就断片。
- **表达**：线下习惯“端着”，线上需要真实、生活化、交朋友式表达，老板转不过来。

### 被验证有效的打法

- 内容围绕**客户问题**，不围绕自家货架：送礼选什么价位、存茶怎么防潮、新手怎么避坑。
- 做“人心账号”而不是流量账号：几百精准播放即可，靠长期信任沉淀复购和转介绍。
- 老板个人 IP，讲真实故事与场景。
- 三层获客入口：本地搜索（大众点评 / 高德）→ 微信私域（成交即加微，朋友圈 60% 干货 + 30% 日常 + 10% 产品）→ 内容获客（周期 2–3 个月，信任度高）。

### 已有付费替代

- 短视频代运营 / 陪跑。
- 私域运营课程。
- 包装设计、节日礼盒定制。

### 机会判断

- **最痛**：内容获客 + 老客维护。
- **最容易演示**：用他讲茶的一段微信语音 → 30 秒口播视频脚本 + 字幕视频；从微信备注整理“送礼名单”（需授权）。
- **最难**：持续产出；老板不愿出镜；内容效果周期长。

## 三、做美容店的

### 痛点

- **客户档案粗放**：纸质本、Excel、微信分散记录；过敏史、皮肤状态、卡项剩余、消费偏好无存档；换人接待重复问，员工离职还会带走客户。
- **预约排班乱**：微信群接龙、口头预约，撞单、爽约、店长手排班出错。
- **复购没人跟**：沉睡会员（超 60 天未到店）一大把，卡项到期、生日无提醒，全靠老板娘想起来。
- **员工管理**：技师流动率高，提成结构复杂（服务 / 开卡 / 产品 / 套盒），月底手工核算容易起纠纷；员工只盯项目提成，不关心老客复购。
- **内容获客与合规**：朋友圈天天发项目广告，顾客屏蔽；社区爆款方法论是“写生活痛点，不写美容项目”；同时不能宣称疗效（排毒、治疗痘肌等），有广告合规风险。

### 已有付费市场

- 门店 SaaS：预约、档案、耗卡、提成核算、企微 SCRM。
- 拓客公司：99 元体验卡、转介绍、异业合作。
- 朋友圈文案课 / 模板包。

### 机会判断

- **最痛**：沉睡会员 + 员工带走客户 + 提成核算。
- **最容易演示**：从客户本 / Excel 挑 20 个 60 天未到店客户 → 唤醒名单 + 个性化回访话术 + 3 条朋友圈。
- **最难**：客户数据授权；效果承诺（不能保证回店）；老板不愿换系统。

## 四、金桂集团的小领导

### 公司背景（公开信息）

- **泸州金桂控股集团有限公司**：泸州市属国企、金融控股集团。
- 注册资本 100 亿元；2017 年成立；2026 年 8 月完成集团化更名，进入“集团化管控、实体化运营、规模化发展”阶段。
- 业务方向：金融资本、金融服务、金融科技、投资、咨询、供应链管理；旗下有商业保理等子公司。

### 中层管理者通用痛点

- **“信息税”**：收集日报、整理会议纪要、汇总数据、写周报 PPT、转达要求、跟进进度。
- **材料生产**：汇报、总结、方案、讲话稿——有素材，但拼得慢，怕写不到点上。
- **知识随人走**：团队经验、项目资料散在个人电脑和微信里，人一走就断档。
- **不敢用公网 AI**：国企 / 金融背景对数据外流极敏感，豆包再好也不敢把内部材料传上去。
- **对上呈现**：小领导的核心诉求往往是“在上级面前呈现得好、汇报得清楚”，不只是自己省事。

### 国企金融集团特有场景

- 集团化后的制度 / 流程 / 权责梳理。
- 监管政策跟踪与解读（金融监管总局、国资委、地方金融局等）。
- 投资项目的尽调 / 可研资料整理。
- 合规检查、审计留痕、版本追溯。
- 报表与经营分析（数据口径、取数权限是门槛）。

### 机会判断

- **最有时效性**：集团化刚完成，制度 / 流程 / 权责正在整合；监管政策跟踪是长期刚需。
- **最适合 okf_kb**：内网离线、资料不出门、每句话有出处、权限与审计齐全。
- **最大现实约束**：小领导通常不是掏钱的人；预算要走部门 / 信息中心 / 采购，国企可能要求资质、比价、招标。

## 五、横向结论

1. **豆包解决“写一段”，没解决“持续产出”**——今天写一条朋友圈，明天还得再想；内容运营是每天 / 每周的事。
2. **通用 AI 不知道他家的事**——不知道库存压了什么、哪个会员快到期、下周是什么节日、隔壁在打什么价。
3. **老板不缺建议，缺“替我把这件事做完”**——时间被店拴死，最愿意为“你帮我做”付费，而不是“你教我怎么做”。
4. **已有付费替代证明意愿**：短视频代运营、门店 SaaS、文案课、进销存软件都有人花钱。空白在于：**便宜、不用学、能持续、看得见到店 / 复购**。
5. **三类店共性**：客户资产 + 内容获客最值钱；员工管理只对美容院是刚需；数据统计是共性，但录入是死穴。
