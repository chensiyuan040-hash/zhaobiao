# 04 · 下一步行动清单

> 目标：先跑出一个付费客户，再谈产品化。  
> 原则：演示一个小结果 → 换一个真实任务 → 换一份付费。

---

## 一、本周（2026-11-10 起）

### 1. 收集真实材料

- [ ] 商店：店面照、货架 / 冰柜照、在卖商品清单、近期收款记录或小票。
- [ ] 茶叶店：产品照、老板讲茶的一段语音、微信备注里的老客名单（经授权）。
- [ ] 美容院：客户本 / Excel 的脱敏样本、现有朋友圈截图、在推的项目和价格。
- [ ] 金桂：公开政策 / 制度 / 同业案例 30–50 份；一个真实材料题目。

### 2. 做“万能演示包”v1

- [ ] 一条 15 秒竖向视频（先用自己的素材练手）。
- [ ] 一份 7 天朋友圈 / 社区群内容包模板。
- [ ] 一页纸经营简报模板。
- [ ] 把三样打包成一个可复用的文件夹 / 模板。

### 3. 约演示

- [ ] 茶叶店：先约，钩子“老板 IP + 送礼名单”。
- [ ] 美容院：钩子“20 个沉睡客户唤醒名单”。
- [ ] 商店：钩子“临期清单 + 补货建议”。
- [ ] 每次演示只带一个钩子，不要一次讲十个能力。

### 4. 金桂线

- [ ] 确认小领导的部门、职级、能否引荐信息部门 / 办公室。
- [ ] 准备“政策检索 + 材料初稿”演示。
- [ ] 用公开材料，不碰内部文件。
- [ ] 先卖“一次梳理 / 一份材料”，不卖平台。

## 二、30 天目标（建议）

- [ ] 完成 **1 次金桂演示**，拿到一个真实任务。
- [ ] 沉淀 **1 套可复用演示包**（视频模板 + 内容模板 + 简报模板）。
- [ ] 记录客户最常问的 10 个问题，作为下一版方案输入。

## 三、待确认事项

| # | 问题 | 为什么重要 |
|---|---|---|
| 1 | 三位老板与你是什么关系？熟人 / 老客户 / 陌拜？ | 决定演示方式和成交速度 |
| 2 | 他们现在每月在内容 / 软件 / 代运营上花多少钱？ | 决定定价锚点 |
| 3 | 谁做决策？老板本人还是老板娘 / 店长？ | 决定演示对象 |
| 4 | 金桂小领导的部门、职级、预算权限？ | 决定是先做试点还是先找上级 |
| 5 | 你每周能投入多少时间交付？ | 决定接几个客户、是否产品化 |
| 6 | 你想先做“替老板干”的服务，还是“给老板用”的工具？ | 决定下一步是报价单还是原型 |
| 7 | 定价：月度服务几百 / 几千？企业试点几万？ | 决定客户筛选 |
| 8 | 合同、收款、发票怎么处理？ | 决定能否接企业单 |

## 四、风险与边界

| 风险 | 应对 |
|---|---|
| 客户数据泄露 | 只在店内使用；不复制、不带走；必要时签简单保密条款 |
| 效果承诺纠纷 | 不承诺涨粉 / 到店 / 成交；只承诺交付物和交付时间 |
| 广告合规 | 美业不宣称疗效；食品不虚假宣传；茶叶不宣称保健功效 |
| 国企采购门槛 | 先做部门级小试点；必要时挂靠已有供应商 |
| 持续交付能力 | 尽早模板化：视频模板、内容模板、简报模板 |
| 同质化竞争 | 豆包 / 剪映免费；差异是“持续 + 懂他家的事 + 有人负责” |
| 客户不愿录入数据 | 从现有收银 / 进销存 / 微信导出；语音、拍照补充；不做重系统 |

## 五、建议的第一次演示脚本（小店通用）

1. **开场（1 分钟）**
   > “我不是来卖软件的。你给我一张店里的照片 / 一段你平时介绍产品的话，我先给你做一条能发的视频，你看着有用再说。”

2. **要材料（2 分钟）**
   > “你平时怎么跟客人介绍这个产品？说一段就行，我录下来。”

3. **现场 / 48 小时交付（10 分钟展示）**
   - 一条 15 秒视频
   - 3 条朋友圈文案
   - 一页纸简报（如果有收款记录）

4. **提问（5 分钟）**
   > “这个如果每周都有人替你做好，你觉得值多少钱？”  
   > “你店里现在最头疼的是哪件事？”

5. **收尾（1 分钟）**
   > “这个我先免费帮你做一次。做完你觉得值，我们再谈按月；觉得不值，你也没损失。”
