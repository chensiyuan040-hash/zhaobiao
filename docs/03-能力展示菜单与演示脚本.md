# 03 · 能力展示菜单与演示脚本

> 目标：不是“介绍 AI”，而是**用一个他明天就能用的小结果，让老板自己说出需求**。  
> 原则：只演示一个结果；用他的真实材料；不讲技术名词；先免费做一次，再谈按月。

---

## 0. 展示原则

1. **一家店只演示一个钩子**，不要一次摆十个能力。
2. **用他的材料**：店面照、产品照、菜单、微信语音、客户本（经授权）。
3. **当场或 48 小时内交付**，让他看到“这么快就能有”。
4. **不承诺效果**：不保证涨粉、不保证到店、不保证成交。
5. **演示后要一个真实任务**：从“看我做”变成“帮我做”。
6. **让客户自己报价**：“如果这个每周都有人替你做好，你觉得值多少钱？”

---

## 1. 万能演示包（三家小店共用，做一次复用三次）

用他的真实材料，交付三样东西：

| # | 交付物 | 内容 | 制作方式 |
|---|---|---|---|
| 1 | **15 秒同城引流视频** | 店面 / 产品照片 + 字幕 + 价格钩子 + “到店暗号” | `video-studio` 竖向短视频 |
| 2 | **7 天朋友圈 / 社区群内容包** | 每天发什么、几点发、配什么图、评论区怎么回 | 通用 AI + 模板 |
| 3 | **一页纸“今日经营简报”** | 卖得最好的 3 样、毛利、明天该补什么、临期提醒 | 收款记录 / 小票照片 → AI 整理 |

**演示话术：**

> “你给我一张店里的照片、一段你平时怎么介绍产品的话，我 10 分钟给你出一条能发的视频。先看效果，觉得能用再说。”

**需求暴露点：**

- “这个能天天有吗？” → 月度内容服务。
- “能不能告诉我进什么货？” → 数据 / 库存服务。
- “我这些老客怎么维护？” → 客户资产服务。

---

## 2. 商店老板：钩子是“临期 + 动销”

### 演示

拍一张货架 / 冰柜照片 → 生成：

- 临期清单（按保质期排序）
- 本周补货建议（动销 + 季节 + 天气）
- 3 条朋友圈 / 社区群文案

### 他会问

- “这个能天天有吗？”
- “能不能告诉我进什么货？”
- “能不能帮我把临期清掉？”

### 可接的单

- 月度“经营简报 + 内容包”。
- 一次性“库存清理 / 节日促销方案”。
- 社区群 / 外卖运营陪跑。

### 用哪个项目

- `video-studio`：活动视频、产品视频。
- `ui-polish`：简报页面、活动 H5。
- 通用 AI：数据整理、文案、选品建议。

---

## 3. 茶叶店老板：钩子是“老板 IP + 送礼节点”

### 演示

1. 用他讲茶的一段微信语音 → 30 秒口播视频脚本 + 字幕视频（不用出镜也能做）。
2. 从他微信备注 / 聊天记录整理“中秋送礼名单”（需他授权，只在店内看）。
3. 给 3 个老客各写一条个性化回访消息。

### 他会问

- “这个号能不能做起来？”
- “我这些老客怎么维护？”
- “节日礼盒怎么卖？”

### 可接的单

- 月度短视频代做（口播 / 产品 / 冲泡教程）。
- 节日礼盒方案（文案 + 海报 + 价格梯度）。
- 客户档案整理 + 节日提醒。
- 朋友圈内容日历（60% 干货 + 30% 日常 + 10% 产品）。

### 用哪个项目

- `video-studio`：口播视频、产品视频、冲泡教程。
- 通用 AI：文案、名单整理、回访话术。
- `ui-polish`：礼盒 H5、产品展示页。

---

## 4. 美容院老板：钩子是“沉睡会员 + 朋友圈”

### 演示

1. 从她的客户本 / Excel 里挑 20 个 60 天未到店客户 → 唤醒名单 + 个性化回访话术。
2. 3 条“生活痛点型”朋友圈（不写项目广告，不宣称疗效）。
3. 一个简单的拓客活动方案（99 元体验卡 + 转介绍机制 + 海报文案）。

### 她会问

- “这些人真能回来吗？”
- “我员工能不能也这么用？”
- “提成能不能自动算？”

### 可接的单

- 月度内容 + 复购唤醒。
- 拓客活动方案。
- 提成核算表 / 排班表模板。
- 员工话术培训（轻）。

### 用哪个项目

- `video-studio`：项目科普视频、顾客案例（需授权）。
- `ui-polish`：预约页、客户档案页、活动 H5。
- 通用 AI：文案、话术、提成表。

### 注意

- 客户数据只在店内使用，不复制、不带走、不外传。
- 美业广告合规：不能宣称“排毒”“治疗痘肌”等医疗效果。
- 不承诺“唤醒率”“回店率”。

## 5. 金桂小领导：三个“拿得出手”的演示

### 演示 1：一句话找到依据（`okf_kb`）

准备 30–50 份**公开**政策 / 制度 / 同业案例，现场问：

> “集团化后，子公司管控有哪些要求？”

输出：

- 答案
- 出处（文件、条款、版本）
- 原文段落
- 相关制度 / 案例

**暴露的需求**：写材料时找不到依据、怕引错、版本乱。

### 演示 2：一份材料初稿（`okf_kb` + 通用 AI）

给一个题目，比如“集团化后子公司管控方案”，30 分钟出：

- 三级大纲
- 初稿
- 引用清单（每条依据来自哪份文件）

**暴露的需求**：材料拼得慢、怕写不到点上、怕领导改。

### 演示 3：会议纪要 → 待办（通用 AI）

一段 5 分钟录音 → 纪要：

- 决议事项
- 待办人
- 截止时间
- 风险 / 待确认

**暴露的需求**：会后跟进漏、没人愿意写纪要。

### 可接的单

- 部门级“政策 / 制度梳理 + 材料代写”轻咨询。
- 小范围知识库试点（`okf_kb`）。
- 监管政策周报 / 月报模板。
- 会议纪要 + 待办跟踪流程。

### 注意

- 只用公开材料做演示，不碰内部文件。
- 不承诺“替代人”“自动决策”。
- 国企采购：先做部门级小试点，别一上来卖平台。

## 6. 能力对应表

| 能力 | 客户听得懂的说法 | 对应演示 | 对应付费 |
|---|---|---|---|
| `video-studio` | “一句话出一条能发的短视频” | 15–30 秒引流 / 口播 / 产品片 | 月度内容代做 |
| `ui-polish` | “做出来的页面不像模板，像正经产品” | 简报页、礼盒 H5、预约页 | 轻工具 / 展示页 |
| `okf_kb` | “内部资料不上网，也能问、能查、能引用” | 政策检索 + 材料初稿 | 部门试点 / 梳理服务 |
| 通用 AI | “替你把文案、表格、纪要、方案做掉” | 内容包、经营简报、会议纪要 | 轻咨询 / 月度服务 |

---

## 7. 演示顺序（建议）

1. **万能演示包**——三家小店都能用，做一次复用三次，成本最低。
2. **茶叶店、美容院先演示**——内容需求最明确，最愿意试。
3. **商店老板用“临期清单”钩子**——他最痛的是库存，不是内容。
4. **金桂单独走“材料 + 检索”演示**——别和小店混在一起，话术完全不同。

---

## 8. 成交话术

### 开场

> “我不是来卖软件的。你给我一张店里的照片 / 一段你平时介绍产品的话，我先给你做一条能发的视频，你看着有用再说。”

### 演示后

> “这个如果每周都有人替你做好，你觉得值多少钱？”  
> （让客户先报价，不要自己先报。）

### 异议处理

| 异议 | 回应 |
|---|---|
| “我没时间学” | “你不用学，我替你做。你只需要给我照片 / 语音。” |
| “太贵了” | “先做一个小的，几十 / 几百块，觉得值再做月度。” |
| “AI 不靠谱” | “你看这条，能用就留着，不能用就算了，不收钱。” |
| “数据安全” | “你的客户资料只在店里看，我不复制、不带走。” |
| “我以前做过，没效果” | “你之前做的是广告，我做的是客户问题；先试三条，看有没有人问。” |
| “我考虑考虑” | “行，这条视频你先发一周，看看有没有人问；下周我再来。” |

### 成交动作

> “这个我先免费帮你做一次。做完你觉得值，我们再谈按月；觉得不值，你也没损失。”

---

## 9. 边界与注意事项

- **客户数据授权**：美容院客户本、茶叶店微信备注，必须经客户同意；只在店内使用。
- **不承诺效果**：不保证涨粉、到店、成交、唤醒率。
- **广告合规**：美业不能宣称医疗效果；食品不能虚假宣传；茶叶不能宣称保健功效。
- **国企保密**：演示只用公开材料；不复制、不上传内部文件。
- **交付范围写清楚**：改几次、多久交付、包含什么、不包含什么。
- **同质化竞争**：豆包、剪映免费；我们的差异是“持续 + 懂他家的事 + 有人负责”。
