# zhaobiao · 小店与企业 AI 业务机会

> 2026-11-10 调研与思考沉淀。面向三类小店老板（商店 / 茶叶店 / 美容院）和国企小领导，梳理真实痛点、需求地图、能力演示方案。

## 一句话结论

- **个人买“多赚钱、少操心”，企业买“少担责、能交差”。**
- 小老板最愿意为“来客 / 留客”掏钱，最容易做成产品的是“数据 / 员工管理”；两者不重合，是核心矛盾。
- 不要先卖系统。先演示一个“明天就能用”的小结果，再谈按月服务。
- 推荐顺序：三家小店共用的“万能演示包” → 茶叶店 / 美容院 → 商店 → 金桂。

- 金桂集团 = **泸州金桂控股集团**（用户确认）。
- 我们的能力载体：
  - `okf_kb`：可内网离线部署的 LLM 知识库 / 知识图谱系统，带出处、审核、权限、MCP 接口。

## 使用建议

- 对外演示只讲结果，不讲技术名词：不说“知识图谱”，说“一句话找到依据、每句话有出处”。
- 客户数据（美容院客户本、茶叶店微信备注等）只在客户店内使用，不复制、不带走、不外传。
- 社区调研的样本偏差与未核实数据，见 01 文档末尾。
